## 考公学习站（d:/C/考公）技术栈确认与宝塔部署改造
- 技术栈：React 19 + vinext（OpenAI Sites 生成的类 Next RSC 框架）+ Vite 8 + Tailwind 4 + shadcn 风格组件；数据库 Cloudflare D1（代码直接用 env.DB 原生 API），专为 Cloudflare Workers 构建。
- 问题：`cloudflare:workers` 模块 + Worker 构建产物，无法直接跑在宝塔 Node 环境。
- 改造（已完成，后续多次迭代，最终版 2026-09-10）：
  - ~~Miniflare API 直连方案失败~~：Miniflare 4 默认把 `.js` 当 CommonJS 解析（需 `modulesRules` 覆盖）、`index.js` 含动态 import 无法静态收集模块、modules 数组模式无 main 标记导致 404、`d1Databases` 需对象+字符串值、监听选项是顶层 `port`/`host` 而非 `listen`。
  - **最终方案：prod.mjs 包装官方 `wrangler dev`**（spawn `node node_modules/wrangler/bin/wrangler.js dev --config dist/server/wrangler.json --port $PORT --ip $HOST`），首次启动自动执行 `wrangler d1 execute DB --local --file drizzle/0000_fuzzy_onslaught.sql` 建表（幂等，marker 文件 `.wrangler/db-initialized`）。本地实测首页 200 + API 200。
  - `package.json` 有 `start:prod` 脚本和 devDependency `miniflare`（已不再必需但保留）。
  - `lib/server-db.ts` 的 safeRequest 从比较完整 origin 改为比较 host（解决 Nginx 反代后协议不一致误报跨域）。
- 部署路径：宝塔 Node ≥22.13 → npm ci → npm run build → PM2 跑 server/prod.mjs（端口 3000，env PORT 可改）→ Nginx 反代 + SSL。
