# 软软上岸

一个面向零基础阅读的 30 天考公学习站。默认部署为仅创建者可访问的私人站点。

## 已实现

- 30 天、90 个公共科目学习任务，支持每天 2 / 3 / 4 / 6 小时。
- 9 节原创入门课，5 道带解析的小练习，答错后进入复盘本。
- 真题、官方大纲和公开经验的来源链接、分类、搜索、收藏。
- 每天首次打开时自动检查资料，保持打开期间每小时检查是否跨天；手动检查间隔 5 分钟。关闭页面后不会自行抓取。
- 四个固定来源的服务端收集：华图真题索引、132 公考申论、QZZN 行测版块、官方考试大纲入口。只存标题与原文链接，不下载或转载完整试卷、帖子、付费课程。
- 来源允许列表、重定向校验、robots.txt 检查、超时、页面大小上限、去重、收集锁与逐源结果。
- D1 保存设置、任务进度、收藏、练习结果与笔记。没有用浏览器存储代替持久化。

## 本地开发

使用当前锁文件安装依赖：`npm ci`。运行 `npm run dev`。

数据库结构在 `db/schema.ts`，迁移在 `drizzle/`。本地首次启动前需用 Wrangler 将迁移应用到 Vite 插件使用的本地 D1；生产迁移由 Sites 部署应用。不要在运行时建表。

`npm run build` 构建 Cloudflare Worker。`node --experimental-strip-types --test tests/collector.test.mjs` 检查收集规则和学习计划；`npx tsc --noEmit --incremental false` 检查类型。

## 内容与范围

默认公共科目通用路线，不根据省份声称生成当地专用考试大纲。省份用于资料检索；专业科目另排。模拟考试日保留本科完整时长，准备和复盘可移至相邻日期。本站原创练习明确区别于第三方真题与回忆版。

最初核对资料：2026-09-09。具体出处保存在 `lib/study-data.ts`；自动更新范围在 `lib/collector.ts`。官方来源目前检查已收录的大纲入口，不是全国省级公告全网监控。外部网站可能限流、改版或要求登录，界面显示每个来源的真实状态。

本应用使用单个私人学习空间。若未来要共享给多人，先增加逐用户身份和记录隔离，再调整 Sites 访问范围。
